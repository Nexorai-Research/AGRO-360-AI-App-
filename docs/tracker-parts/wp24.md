## Phase 24: standard error and exception handling (found testing the running app, 20 November 2026)

Found by opening every menu screen of the running app on the emulator against the local mock server. Several screens broke while drawing when an answer lacked a field (`d.totals.netSales`, `g.summary.taxable`, a missing date, a missing amount), and with nothing to catch it the whole app went down. Texts in `i18n-parts/wp24.json`.

| Feature | State | Test |
|---|---|---|
| 24.1 Every screen of the app has its own error boundary (Expo Router `unstable_screenErrorBoundary` on the Stack, `src/ui/ScreenErrorBoundary.tsx`): a screen that breaks shows "This screen could not be shown" with Try again and Go back; the menu and the rest of the app keep working | DONE | `__tests__/wp24.test.tsx` |
| 24.2 One global handler (`src/errors/global.ts`) for errors nothing else caught (a button handler, a timer, a promise nobody waited for): kept in a short list for support (message only, cut to 200 characters, no personal data), sent with the usage report when it is on; the platform's own handling is kept | DONE | `__tests__/wp24.test.tsx` |
| 24.3 Values shown on screen never break it: a missing or broken amount, quantity or date shows "–" (`formatINR`, `formatQty`, `shortDate`, `fmtDate`); arithmetic (`dec`, `add`, ...) stays strict so a wrong amount is never hidden in a calculation | DONE | `__tests__/wp24.test.tsx` |
| 24.4 Bug fixed in 11 screens: `open?.id === row.id` was true for a row without an id while nothing was selected, and the next line then read a field of nothing (it broke the batches screen); now `open && open.id === row.id` | DONE | `__tests__/wp24.test.tsx` |
| 24.5 AI digest and risk register counts read safely (a missing count is 0) | DONE | `__tests__/wp24.test.tsx` (helpers), existing AI tests |
| Already in place: server errors become a translated message with a reference code and Retry on every screen (`src/api/errors.ts`, `StateView`, `Notice`); no network is its own "offline" state | DONE | existing tests |
