## Staff, payroll, more reports and home extras (branch `stf`)

All lines: mocked API client, NOT run against the real backend or a phone. Response and request shapes are written by hand from the backend source (`apps/api/src/hr.controller.ts`, `reporting.controller.ts`, `modules/hr`, `modules/reporting`), not generated. Every write sends one Idempotency-Key per user action (same key on a retry after a lost answer, new key when the body changes); edits and exit send `If-Match` (the version read earlier). No tenant id is sent. Texts: `i18n-parts/stf.json` (en, hi, mr, same keys; Hindi and Marathi need a native speaker review). Tests: `__tests__/stf-hr.test.tsx` (15), `__tests__/stf-payroll.test.tsx` (21), `__tests__/stf-reports-home.test.tsx` (14); `__tests__/home.test.tsx` still passes (14; one assertion now counts only the dashboard calls).
